Candidate 1: Deconstruct the 3,000-Line Agent Kernel & Mega-Constructor

Following the Python retirement (W4–W6), LLM orchestration, docparse, MinIO readers, and FP&A tools have all moved into Go. aiagent.Agent and NewAIChatHandlerWithOperationalReadersAndGovernanceAndRetail have become the primary architectural friction hot spot. Deepening this into separated Planner, Context Assembler, and Tool Provider modules will immediately unlock testability, eliminate constructor bloat, and allow domain modules to self-register their tools cleanly.
