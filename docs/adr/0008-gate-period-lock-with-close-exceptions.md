# Gate period lock with close exceptions

Period lock is permitted only when every Blocking Exception in the Close Period is closed with a Verified Resolution, Accounting Conclusion, or Approved Waiver, and every remaining Warning Exception has been acknowledged. The lock records a Close Snapshot. The Agent may detect, diagnose, recommend, trigger user-authorized workflows, and revalidate exceptions, but it may not change accounting data, grant waivers, post entries, or lock the period autonomously; this preserves human accountability while making exception control systematic and auditable.
