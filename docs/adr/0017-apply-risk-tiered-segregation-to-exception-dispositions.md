# Apply risk-tiered segregation to exception dispositions

Verified Resolution is closed by the rule engine after explicit passing revalidation and requires no ceremonial human approval; routine remediation and Warning acknowledgement may allow the Exception Owner to act as reviewer. Every High-Risk Disposition requires three distinct Users as Exception Owner, Exception Reviewer, and Exception Approver, while Standing Waiver approval is elevated to Group Finance. An Exception Owner can never approve their own disposition. When a Legal Entity lacks enough staff, approval moves upward to Group Finance rather than weakening the separation. System Admin and Agent components have no disposition authority, and deterministic routing owns formal assignment while Agent output remains advisory.
