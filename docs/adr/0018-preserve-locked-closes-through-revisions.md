# Preserve locked closes through approved revisions

Frozen Projection, Frozen Control Profile, and Close Snapshot records are never changed. A Post-Close Exception defaults to an approved Prospective Adjustment in a later open period; reopening is an exceptional, materiality-gated path using a Period Reopen Request and a new numbered Close Revision. Issued financial information triggers the highest-risk workflow and a human Prior-Period Error Assessment, never an automated restatement conclusion. The revision normally inherits the original Frozen Control Profile unless the approved reason is an error in that policy itself. ERP corrections use new reversal and adjustment vouchers rather than deleting or reversing the status of historical vouchers, and every prospective treatment creates a Forward Tracking Item in its target period.
