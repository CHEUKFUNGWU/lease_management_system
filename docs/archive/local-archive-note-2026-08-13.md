## 需要知道的一个限制

从远端下架 **不等于** 从历史中抹除。这些文件在归档前的所有提交仍保留在 git 历史里，同事执行以下命令依然能读到：

```bash
git log --all --diff-filter=D -- 'docs/租赁平台进阶提升方案.md'
git show <commit>:docs/租赁平台进阶提升方案.md
```

要彻底抹除需要改写历史并强制推送，那会让所有人已有的 clone 失效，**不建议**。当前做法解决的是「同事浏览仓库时误把旧定位当现状」，不是保密问题。
