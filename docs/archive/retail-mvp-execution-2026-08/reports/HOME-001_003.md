# 票二：HOME-002 —— 今日经营简报

## 实现要点

- **首屏自动晨检**（B1）：`home/BriefColumn.tsx` 挂载即发现最新模拟数据集（`retailAnalyticsApi.latestSimulationDataset`，无数据集则回落 production + 今日 as_of），然后经既有零售 Agent 路径自动跑一次 `aiChatApi.chat`（`skill_id=retail_operations@v1` + `page_context.filters`），消息为新增 i18n key `home.brief_prompt`（不含情景/诊断/行动提议关键词，后端意图判定为 `pulse_summary`）。
- **组件全部复用**（B2）：`DataTrustBar`（pulse envelope）、`ToolChip`（tool_calls）、`ConfidenceBadge`、`SourceCitation`（带 `[n]` 编号）、`ThinkingTrace`（agent_plan 格式化为轨迹文本）、`SeverityDot`（关注门店信号）。`signalLabel` / `formatSignalValue` 复用 `operating-pulse/logic.ts`。grep 确认无第二套可信度/引用/置信度渲染（`BriefView.test.tsx` 源码断言）。
- **角色感知**（B3）：中间栏按 `canViewHomeBrief`（admin/readonly/auditor）分支；editor/reviewer/approver 渲染 `home/WorkQueueFocus.tsx`（工作队列为主，复用同一批 dashboard 组件，**不是权限错误**）。右栏对所有角色一致（`home-flow.test.ts` 断言分支内无 RightColumn）。
- **三态**（B4）：`classifyHomeBrief` 区分 `no_data`（decision_ready=false 且两侧 observed store-days 均为 0，即正式数据无事实）、`not_decision_ready`（覆盖不足，不给确定结论）、`scope_denied`（`retail_operations.reason === "scope_denied"` 优先于一切覆盖信号，文案用 `api.scope_denied`，测试断言渲染结果**不含「暂无数据」**）；另有 `needs_input` 与 `error`（带重试）。
- **请求门控**（B5）：`home/briefGate.ts` 模块级 memo —— 同一 SPA 会话内重复进入首页复用同一 in-flight promise 与结果；失败不缓存（重试按钮可重新执行）。并发去重、键含 filters、失败重跑均有测试。
- 追问 composer：走 `RetailAIDrawer` 已验证的调用方式（`aiChatApi.chat` + page_context），渲染与简报同一套共享组件。
