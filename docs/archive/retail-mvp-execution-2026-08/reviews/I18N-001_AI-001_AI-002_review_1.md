## 2. i18n 倒逼出的一个真实潜在缺陷

旧代码（`main`，`operating-pulse/page.tsx:52` 与 `:64`）：

```tsx
const statusKind = status.label === "完整" ? "neutral" : "warning";
```

**这是拿显示文案做逻辑判断。** 一旦切到英文，该比较恒为 `false`，**所有 KPI 的状态标签会静默变成 warning**——界面上每张卡片都显示"异常"，而数据其实是完整的。

实施者没有把比较改成"匹配三种语言"（那是把 bug 换个形状），而是重构 `metricStatusLabel` 返回稳定的 `status: "complete" | "partial" | "missing"` 码，与本地化 `label` 分离：

```tsx
const statusKind = status.status === "complete" ? "neutral" : "warning";
```

**根因修法正确。** 这类缺陷只有在真正开启多语言时才会暴露——这也说明「补完 i18n」不只是文案工作。
