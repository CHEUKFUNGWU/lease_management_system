# 票二：AI-001 —— AI 可解释组件层

## 2.1 问题

后端**已经具备完整的可解释能力**（run events、trace、evidence、confidence），但界面只显示最终答案。DESIGN.md §9 列了要什么，组件一个都没建。

## 2.2 必须实现（规格见 DESIGN.md §9，不要另行设计）

| 组件 | 消费 | 要求 |
|---|---|---|
| `<ToolChip>` | run events 的 tool 调用 | 工具名 · 数据量 · 耗时 |
| `<ThinkingTrace>` | run trace | **默认收起**，可展开 |
| `<SourceCitation>` | `evidence.source_systems` | 统一引用角标，**可点击回到证据** |
| `<ConfidenceBadge>` | `confidence` + `reason` | **0.40 与 0.90 必须看得出区别**，且能看到降级原因 |

硬规则（DESIGN.md §9）：

- **AI 建议与系统正式数据必须视觉可区分**，不得混排成同一种卡片；
- **`scope_denied` 要如实显示**，不得软化成「暂无数据」——ERR-002 已提供独立文案，直接复用；
- 颜色不是唯一信号，`ConfidenceBadge` 需有文字或形状区分。
