## B. AI-001 — 可解释组件层

四个组件（`web/app/components/`），全部接入 ai-chat 消息渲染：

| 组件 | 消费 | 实现 |
|---|---|---|
| `<ToolChip>` | run events 的 tool 调用（`AgentToolCall`） | 工具名 · 状态 · 数据量（输出字符数）· 耗时（`duration_ms` 存在才渲染，不伪造） |
| `<ThinkingTrace>` | run trace（`Message.thinking`） | **默认收起**（A3 测试断言 `aria-expanded="false"`），点击展开 |
| `<SourceCitation>` | `evidence.source_systems`（`RuntimeSource`） | 统一引用角标，有 URL 可点击回证据；无标题时回退 type/id，不匿名 |
| `<ConfidenceBadge>` | `confidence` + `reason` | 三档（low/medium/high）用圆点颜色 + 文案 + 边框三重区分（A2：0.40 → is-low/低置信，0.90 → is-high/高置信，测试断言不同）；降级原因放原生 `title` 属性——不经过 portal，可读可测 |

- ai-chat 页面：thinking → ThinkingTrace、sources → SourceCitation、toolCalls → ToolChip 行、confidence（Message 类型新增，从 run 响应映射）→ ConfidenceBadge
- `StatusTag` 补上 classic JSX runtime 需要的 React import（SeverityDot 同款修复）
