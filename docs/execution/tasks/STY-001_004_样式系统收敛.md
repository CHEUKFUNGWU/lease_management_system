# 票一：STY-001 —— 令牌收口成单一真相源

## 1.1 问题

设计令牌有**两套定义且已漂移**（DESIGN.md §1）：`tokens.ts` 喂 Ant Design，`globals.css` 的 `:root` 喂所有自定义 CSS。结果是 AntD 卡片和自己写的卡片**边框颜色天生不同**。

## 1.2 取值已定，不要自行判断

漂移不是"哪边对"的问题，而是**哪个值属于成体系的灰阶**。`--mono-*` 是一条完整的灰阶（0/20/40/60/70/90/95/98/100），`#E5E5E5` 不在这条阶上，是离群值。

| 项 | `tokens.ts` 现值 | `:root` 现值 | **定为** | 谁改 |
|---|---|---|---|---|
| `border.default` | `#E5E5E5` | `--mono-90` = `#D9D9D9` | **`#D9D9D9`** | 改 `tokens.ts` |
| `border.strong` | `#D9D9D9` | `--mono-70` = `#A6A6A6` | **`#A6A6A6`** | 改 `tokens.ts` |
| `border.subtle` | `#F0F0F0` | `--mono-95` = `#F0F0F0` | 已一致 | — |
| 页面主标题字号 | `display` 32px | `.page-header-title` 28px | **28px**（DESIGN.md §4.1） | 改 `tokens.ts` |
| 页面主标题字重 | 700 | 700 | **600**（DESIGN.md §4.2） | 两边都改 |
| 等宽字体 | `JetBrains Mono` | 未加载，实际用 `ui-monospace` | **`ui-monospace` 栈** | 改 `tokens.ts`（删死配置） |
| 静态深度 | `depth.static` = `1px solid` | `--shadow-static` = 环形阴影 | **环形阴影**（DESIGN.md §6） | 改 `tokens.ts` |

**外观影响**：AntD 组件的边框会**略微变深**（`#E5E5E5` → `#D9D9D9`），与自定义卡片对齐；页面主标题字重由粗变常规。这两项是**预期内的视觉变化**，不是回归。

## 1.3 必须实现

1. 按上表修正 `tokens.ts`；
2. **写 DESIGN.md §1 要求但从未写过的对齐测试**：断言 `tokens.ts` 的颜色 / 字号 / 字重与 `globals.css` `:root` 的对应变量逐项一致。测试要能在改一边忘另一边时失败；
3. 更新 DESIGN.md §1 的漂移表与 §14 的已知偏离表（这两项已解决）；
4. **顺手收窄徽标豁免**（上批 Review §4）：`enforce-design.mjs` 的 `BRAND_BADGE_LINE` 用 `continue` 跳过了整行的三条检查。改成**只豁免内联样式一条**，`!important` 与 `fontWeight` 仍生效。

# 票二：STY-002 —— 三档字重与状态色降级

## 2.1 必须实现

### A. 字重收敛到 400 / 500 / 600

存量：JS/TSX 中 `fontWeight: 700|800` **11 处**，`globals.css` 中 `font-weight: 700|800` **4 处**。

全部降到 ≤600。**层级用尺寸与字距补回来，不要靠加粗**（DESIGN.md §4.2）。

**外观影响**：所有粗体标题变为半粗。这是预期变化。

### B. 状态色不再做面积填充

新建 `<SeverityDot severity="critical|high|medium|low" />`：**8px 圆点 + 常规字色**，替换现有 4 处 `<Tag color="red|gold">`（在 `operating-pulse/page.tsx` 与 `scenario-workbench/page.tsx`）。

依据 DESIGN.md §3.3：彩色只出现在 8px 状态点和图表数据里，不做大面积填充。现在一屏可能出现几十个红色 Tag，真正的异常反而看不见。

**注意**：`<StatusTag>` 是既有的合法组件，**不要动它**。本票只替换 `Tag color=` 这种直接用 AntD 预设色的写法。

**颜色不能是唯一信号**（DESIGN.md 原则 3）：圆点旁必须保留文字标签，圆点本身要有 `aria-label` 或等效可读文本。

## 2.2 明确不做

1. 不动 `<StatusTag>`；
2. 不改图表配色；
3. 不动 `--state-*` 语义色令牌本身。

# 票三：STY-003 —— AppLayout 去内联样式与 JS hover

## 3.1 范围严格限定

`web/app/components/AppLayout.tsx` **一个文件**：30 处内联 `style={{}}` + 6 个 JS hover handler。

**全仓其余 876 处内联样式本票一律不动。** ENF-001 的检查已经在防新增，存量分批清理，本票只做这一个文件——它是暗色模式做不了的直接原因，也是有缺陷史的那个文件。

## 3.2 必须实现

1. 30 处内联样式迁到类名（`.app-header` / `.app-sider` / `.app-content` 之类），声明值**原样搬运**；
2. 6 个 `onMouseEnter` / `onMouseLeave` 改样式的写法，换成 CSS `:hover, :focus-visible`。

**这一条顺带修一个真 bug**：JS hover 只对鼠标生效，**键盘用户 focus 时拿不到任何反馈**。改成 CSS 伪类后键盘可见性自动就有了。

## 3.3 本票的验收标准是「外观不变」

与另外三票不同，**STY-003 不应产生任何视觉变化**——它是纯粹的机械搬运。

因此：

- 迁移时**不要顺手调整**任何数值（间距、颜色、圆角一律照搬）；
- 若发现某处内联值与 DESIGN.md 冲突（例如硬编码颜色），**不要在本票修**，记进报告的附带发现，留给后续票。

## 3.4 验收

# 票四：STY-004 —— 字体自托管

## 4.1 问题

`globals.css:5` 用 CSS `@import` 从 Google Fonts 加载 Inter，全仓 `next/font` 引用为 **0**。

三重代价：CSS 内的 `@import` **渲染阻塞**；产生对 Google 的**外部运行时依赖**（内网/离线部署会静默退化为系统字体）；没有 `size-adjust`，首屏有可见字体跳动。

## 4.2 必须实现

1. 删除 `globals.css` 的 `@import url('https://fonts.googleapis.com/...')`；
2. 改用 `next/font`（自托管），配置 `display: "swap"`；
3. **保留现有中文回退栈**（`"Noto Sans SC", "PingFang SC", "Microsoft YaHei"`）——中文字形不走 Inter，回退栈不能丢；
4. 同步 `tokens.ts` 的 `fontFamily.sans`。

## 4.3 验收
