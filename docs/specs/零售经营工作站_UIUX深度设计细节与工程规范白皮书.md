## 一. Keynote 级单色几何图形体系 (Monochrome Shape System)

### 1.1 设计哲学：严禁彩色 Emoji，拥抱极简单色矢量图形
彩色 Emoji（如 🚨, 🤖, 💡, 🎛️）具有强烈的消费级与娱乐感，极易破坏财务/经营决策软件的严肃性与高级感。
全面转向 **Apple Keynote / SF Symbols / Linear 风格的单色几何 Shape 与 1px 细线轮廓**：

| 语义场景 | 严禁使用 (Emoji) | 规范采用 (Keynote 级单色 Shape / SVG Line) | 配色规范 (Color Token) |
| :--- | :---: | :--- | :--- |
| **AI 助理 / 智能诊断** | 🤖 | `◇` 极简单色菱形星芒 (Sparkle / Diamond Glyphs) | `text-slate-700` 或 `stroke-slate-900` |
| **异常 / 风险告警** | 🚨 / ⚠️ | `△` 空心细线三角形或实心几何圆点 `●` | `text-rose-600` (仅借色，不加花哨渐变) |
| **参数调节 / 沙盘** | 🎛️ / ⚡ | `⊞` / `Sliders` 细线滑动器轮廓 | `stroke-slate-600` |
| **数据源 / 凭证标签** | 🏷️ / 🔍 | `○` 几何圆环 / `FileText` 细线矢量图标 | `text-slate-500` |
| **空状态占位** | 📭 | 极简几何线框虚线立方体 / 优雅单色无衬线字标 | `stroke-slate-300` / `fill-slate-50` |

## 十. 全站文案与功能教程「去 IT 黑话」业务语言规范 (Terminology & Copywriting)

### 10.1 全站「去 IT 黑话」对照词典 (Master Terminology Dictionary)

| 原始 IT / 开发黑话 | 业务人员困惑点 | 规范业务替换词 | 适用页面 / 场景 |
| :--- | :--- | :--- | :--- |
| **`固定 seed` / `seed`** | 用户以为是某种代码或种子 | **「内置标准演示样本」 / 「模拟数据集」** | 帮助教程、数据切换条 |
| **`as-of` / `as_of`** | 纯英文介词短语，非财务术语 | **「分析基准日」 / 「数据截止日」** | 顶栏、筛选器、导出 |
| **`store-days`** | 数据库事实行计算单位 | **「门店有效经营日数」 / 「样本天数」** | 覆盖率提示、数据质量抽屉 |
| **`Working` / `Official`** | 缺少上下文解释的英文词 | **「工作试算底稿」 / 「正式过账台账」** | 报表模式切换、横幅 |
| **`ISO 4217`** | 国际代码编号，用户不知填什么 | **「币种代码 (如 CNY, HKD)」** | 条款比价、ROI 测算、台账 |
| **`source_system IT计台?`** | 暴露后端系统识别代码 | **「数据源系统 (可选)」** | 筛选栏输入框 |
| **`retail-kpi-v1` / `formula_version`**| 暴露 API 语义版本号 | **「标准零售经营 KPI 计算模型」** | 指标说明、AI 回复 |
| **`残差 (Residual)`** | 统计学术语，感觉像系统报错 | **「勾稽尾差」 / 「未分摊杂项」** | 损益分析、瀑布图、对账 |
| **`four_wall_ebitda`** | 纯数据库蛇形命名 | **「门店四墙经营利润 (EBITDA)」** | 导入页面、指标卡 |
| **`idempotent_replay`** | 分布式架构术语 | **「重复请求已拦截 (无需重新提交)」** | 保存行动、导入反馈 |
| **`deterministic-fallback`** | 算法降级模式名 | **「规则引擎直出模式」** | AI 证据抽屉 |
| **`制造设备` / `OEE` / `产线`** | 严重的工厂租赁遗留术语 | **彻底移除，替换为「商圈对比 / 租约预警」** | 经营驾驶舱 (`/performance`) |

### 10.2 功能教程（Help Drawer）人话级重构示例

#### 改造前（充斥开发术语）：
> *“模拟数据来自固定 seed，正式数据来自 POS 导入。7/14/28 天窗口与 as-of 截止日决定「当前 vs 对比」两个区间。覆盖不足时 retail-kpi-v1 指标降级为不可决策。”*

#### 改造后（专业业务语言）：
> *“系统支持切换「演示模拟数据」与「POS 真实经营数据」。您可以选择 7 天、14 天或按月作为分析周期，系统将自动对比基准期数据并标出异常。当某门店数据上报不完整时，系统会明确提示数据覆盖不足，杜绝虚假预测。”*
