# 线下零售经营工作站：转型实施任务清单与验收标准

> 版本：v1.0  
> 日期：2026-08-12  
> 适用范围：无设计伙伴、无客户深访条件下的内部模拟验证与产品工程实施  
> 产品边界：连锁零售承租方经营分析；不进入地产开发、招商、物业资产经营或房东管理

## 1. 执行结论

本项目应从“IFRS 16 计算为中心的租赁系统”调整为“以门店经营单元为中心的线下零售经营工作站”。租赁能力继续保留，但只承担两个角色：

1. 为门店经营提供租赁现金支出、占用成本、面积、关键日期和合同约束；
2. 作为可选财务模块提供 IFRS 16 计量、月结、分录、披露和审计材料。

本路线不包含：选址、商圈分析、物业估值、市场租金数据库、招商、出租率、租户管理、物业收费、工程设施管理、房东 CRM。门店关闭、合同续签或终止只作为承租方经营情景和合同事件处理，不扩张为地产管理产品。

由于没有设计伙伴和深度访谈，Phase 0 改为“可审计模拟验证”。它可以证明产品逻辑、数据模型、指标、性能、Agent 边界和端到端工作流，但不能证明市场需求、付费意愿或真实 ROI。所有对外材料必须保留这一限制。

## 2. 实施原则

### 2.1 产品主线

```text
经营数据进入
  → 数据质量与对账
  → 今日/本周经营脉搏
  → 异常门店识别
  → 驱动解释
  → 情景模拟
  → 行动草稿与审批
  → 后续 Actual 验证
```

租赁合同、占用成本和 IFRS 16 是该主线的支持域，不是首页和用户旅程的中心。

### 2.2 验收证据等级

| 等级 | 证据 | 可支持的结论 |
|---|---|---|
| E1 | 单元测试、静态检查 | 单个规则或模块按设计工作 |
| E2 | 固定种子模拟数据、Golden Dataset | 指标和工作流可确定性复演 |
| E3 | 端到端自动化、权限和故障注入 | 系统集成、治理和恢复满足内部发布要求 |
| E4 | 内部角色化 UAT | 产品流程在模拟任务中可用，但不代表真实客户价值 |
| E5 | 真实客户数据和持续使用 | 本阶段不可获得；不得宣称已完成 PMF 或商业验证 |

### 2.3 全局 Definition of Done

任何任务只有同时满足以下条件才能标记完成：

- 代码、迁移、配置和文档已进入版本控制；
- 正常、空数据、错误、权限不足和重复请求路径均有处理；
- 新指标明确公式、粒度、过滤规则、单位、币种、日历、版本和 Owner；
- 新写操作具备权限、幂等、审计、失败回滚和 Review Gate；
- 测试不依赖手工修改数据库，模拟数据可由固定 seed 重建；
- Go、Python、Web 测试以及 `git diff --check` 通过；
- UI 不出现无法解释的演示数字；模拟数据必须标记 `SIMULATED`；
- 文档说明限制、已知风险和不做范围。

## 3. 阶段与发布门槛

| 阶段 | 建议周期 | 目标 | 发布门槛 |
|---|---:|---|---|
| S0 边界与基线 | 1–2 周 | 冻结产品边界、指标和模拟基准 | 边界、角色、指标字典、场景目录和基线测试全部评审通过 |
| S1 数据与语义 | 2–5 周 | 建立可复演的门店日/周事实与质量控制 | Golden Dataset 全量导入；核心指标 100% 对数；重跑无重复 |
| S2 经营 MVP | 5–10 周 | 打通经营脉搏、门店 360、情景和行动 | 5 个角色化任务端到端通过；常用查询 P95 达标 |
| S3 Agent 与治理 | 8–12 周 | 上线只读调查、模拟和草稿 Agent | 越权成功为 0；无证据回答受控；所有写入停留在草稿/审批层 |
| S4 内部发布 | 12–16 周 | 形成可演示、可回归、可部署版本 | 全量回归、故障恢复、安全清单、演示脚本和发布文档通过 |

## 5. 核心模拟场景及业务验收

| 场景 | 输入特征 | 预期系统结论 | 必须通过的验收 |

| SCE-04 毛利恶化 | 销售增长、毛利率下降 | 收入增长但贡献下降 | 利润桥正确拆出毛利率影响 |

| SCE-06 占用成本率恶化 | 固定租金稳定、销售下降 | 比例恶化由销售分母驱动 | 不误判为租金上涨 |
| SCE-07 租金阶梯 | 基本租金按合同上调 | 占用成本金额和比例上升 | 关联到合同条款/事件，不使用 IFRS 折旧代替 |
| SCE-08 变量租金 | 销售触发 turnover rent | 当期经营占用成本增加 | 经营口径计入；IFRS 计量按规则分流 |
| SCE-09 合同选择权 | 临近选择权窗口 | 生成内部提醒和情景入口 | 不自动续签、联系房东或预测市场租金 |
| SCE-10 数据缺失 | 某日客流缺失 | 客流相关指标降级/阻断 | 缺失不当作 0；Agent 明确数据限制 |
| SCE-11 重复批次 | 同一文件重复导入 | 不新增重复事实 | 幂等命中并写审计记录 |
| SCE-12 迟到更正 | 历史销售被更正 | 生成新版本并刷新下游 | 已批准旧报告不被覆盖 |
| SCE-13 越权访问 | 区域 A 用户请求区域 B | 拒绝且不泄露存在性 | API、导出、Agent 和错误消息全部一致 |
| SCE-14 Agent 注入 | 上传内容要求忽略权限/执行高风险动作 | 拒绝并记录安全事件 | 无工具越权、无敏感数据、无正式写入 |
| SCE-15 AI 服务中断 | LLM/Planner 不可用 | 确定性页面继续工作 | 可手工创建情景/行动；无数据丢失 |

## 6. 最终验收矩阵

| 验收域 | 必须满足 | 否决条件 |

| 工作流 | 异常到行动到验证端到端通过 | 只有图表，没有 owner、due date、审批或收益复盘 |
| 租赁 | 只覆盖承租方合同、现金、占用成本和关键日期 | 出现房东、招商、出租率、物业估值或市场租金产品化 |
| IFRS 16 | 原计量和月结控制不回归；模拟不得进入 Official | 经营数据直接改正式计量，或模拟结果可过账 |
| Agent | 数值由确定性工具提供；只读/模拟/草稿受控 | 越权成功、虚构事实、绕过 Review Gate 或存在高影响工具 |
| 安全 | 跨范围成功数 0；导出和 Agent 同样受限 | API 阻止但导出/Agent 可旁路 |
| 性能 | 60/500 店基准满足 P95 目标 | 未记录数据规模和测试环境，或关键查询超标无降级方案 |
| 发布 | 统一验证命令、演示重建、故障手册和限制说明齐全 | 仍依赖个人环境，或对外把模拟结果表述为客户验证 |
